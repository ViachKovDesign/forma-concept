# ФОРМА — концепт-сайт бюро брендинга заведений

Портфолио **вымышленного** бюро «ФОРМА», которое делает айдентику для пекарен, баров, кофеен и ресторанов. Сайт устроен как выставка: шесть «залов»‑кейсов, у каждого свой шрифт, свой цвет и свои экспонаты — логотип, меню, упаковка, фасад, палитра. Все картинки нарисованы кодом (SVG), чужих фото нет.

> Концепт-проект. Бренд вымышленный, заведения и цифры — примеры. Дизайн и разработка — [ViachKovDesign](https://viachkovdesign.github.io).

## Что внутри

```
index.html            главная: hero → 6 кейсов → Бюро → Процесс → форма → подвал
cases/*.html          6 страниц кейсов
css/main.css          все стили (исходник; при сборке встраивается в страницы)
js/main.js            анимации: плавный скролл, шторки, параллакс, курсор, переходы, форма
vendor/               GSAP 3.15.1, ScrollTrigger, Lenis 1.3.27, шрифты Google Fonts
img/                  favicon, OG-картинки 1200×630
screenshots/          скриншоты проверки
tools/                генератор страниц и рисунки брендов (tools/brands/*.mjs)
DECISIONS.md          принятые решения, по строке на каждое
REPORT.md             отчёт: что сделано, как работает, Lighthouse
```

## Как открыть у себя (без программирования)

1. Скачайте репозиторий: зелёная кнопка **Code → Download ZIP** на GitHub, распакуйте.
2. Дважды щёлкните `index.html` — сайт откроется в браузере. Всё будет видно и читаться.
3. Чтобы работали **переходы между страницами** (обложка расширяется в кейс), нужен локальный сервер — браузеры не делают такие переходы для файлов с диска. Если на компьютере есть Python, выполните в папке проекта:

```bash
python3 -m http.server 8080
```

и откройте в браузере `http://localhost:8080`. Остановить сервер — `Ctrl + C`.

## Как опубликовать на GitHub Pages (бесплатно)

1. Откройте репозиторий на GitHub → **Settings → Pages**.
2. В блоке **Build and deployment** выберите *Source: Deploy from a branch*, ветку `main` (или нужную вам) и папку `/ (root)`. Нажмите **Save**.
3. Через 1–2 минуты сайт появится по адресу вида `https://<ваш-логин>.github.io/<имя-репозитория>/`.
4. Если адрес другой — откройте `tools/build.mjs`, поменяйте строку `SITE_URL` и пересоберите (см. ниже): от неё зависят canonical, og:url и картинка в превью ссылок.

Сейчас в `SITE_URL` прописан адрес `https://viachkovdesign.github.io/forma-concept/` — он совпадает с именем репозитория `forma-concept`. Если переименуете репозиторий, поменяйте и эту строку.

## Как что-то поменять

Страницы собираются небольшим скриптом из данных брендов — так шапка, подвал и подписи одинаковые на всех страницах.

1. Установите [Node.js](https://nodejs.org) (версия 18+).
2. В папке проекта один раз выполните `npm install`.
3. Правьте:
   - тексты и цвета кейса — `tools/brands/<бренд>.mjs` (там же рисунки-экспонаты);
   - тексты главной (принципы, этапы, форма) — `tools/build.mjs`;
   - стили — `css/main.css`; поведение — `js/main.js`.
4. Пересоберите страницы:

```bash
npm run build
```

Скриншоты проверки (нужен запущенный сервер на :8080 и Playwright):

```bash
npm run shots
```

OG-картинки и иконки:

```bash
npm run og
```

Обновить библиотеки и шрифты в `/vendor` (с урезанием шрифтов, нужен `pip install fonttools brotli`):

```bash
npm run vendor
```

## Технологии

HTML, CSS и JavaScript без сборщика и фреймворков. [GSAP](https://gsap.com) + ScrollTrigger — шторки и параллакс, [Lenis](https://lenis.darkroom.engineering) — плавный скролл, View Transitions API — переход «обложка → кейс». Шрифты — Google Fonts: Unbounded, Cormorant, Fira Sans Extra Condensed, Golos Text (через пакеты @fontsource, лицензия SIL OFL).
