# Решения

Каждое решение — одной строкой.

- Названия заведений придуманы свои («Подовый», «Нулевой цикл», «Отвес», «Тамада и сын», «Осадок», «Шу!»), города реальные, адресов и улиц нет — чтобы не совпасть с реальными местами.
- Шесть кейсов = шесть разных визуальных языков: гравюра-печать, строительный чертёж и трафарет, швейцарская сетка, арка и орнамент, пласты осадка, поп-кондитерская.
- Три заголовочных шрифта: Unbounded (широкий гротеск), Cormorant (антиква, прямой и курсив), Fira Sans Extra Condensed (узкий); текстовый — Golos Text на весь сайт. Все — Google Fonts с кириллицей.
- Каждый шрифт заголовков используется двумя кейсами, но в разном начертании (Cormorant прямой/курсив, Fira 800/300).
- Шрифты положены в /vendor из npm-пакетов @fontsource (это файлы Google Fonts), а не подключены с fonts.googleapis.com: нет внешних запросов и проще пройти Lighthouse.
- Шрифты урезаны fonttools до кириллицы, базовой латиницы и типографских знаков: 430 КБ → 235 КБ, Lighthouse главной 84 → 93.
- Валюта в меню не пишется (просто «210»), чтобы не тянуть знак ₽ из ещё одного файла шрифта; в бюджете — «тыс. руб.».
- Палитра сайта: тёплый серый #D9D6D0 и графит #1C1B19; кремового и терракоты нет.
- Цвета кейсов разнесены по кругу: кобальт, сигнальный жёлтый, лайм, гранат, пыльная роза, бирюза.
- Фон окрашивается целиком в цвет кейса (а не тонируется на 20%), цвет и текст подобраны вручную под контраст AA.
- Смена темы — через IntersectionObserver по центральной линии экрана, без GSAP: работает и при «уменьшить движение».
- Страницы собирает маленький Node-скрипт tools/build.mjs; в репозитории лежит готовый HTML, сайт работает без сборки и без сервера.
- CSS встраивается в каждую страницу при сборке (исходник — css/main.css): минус один блокирующий запрос.
- SVG-экспонаты встроены в HTML, а не лежат файлами: так в них работают веб-шрифты и параллакс слоёв.
- Обложки в ленте используют preserveAspectRatio="xMidYMid slice" — один рисунок подходит под пропорции 16:10, 4:5, 21:9, 3:4, 3:2, 1:1.
- Шесть раскладок ленты (a–f) и шесть разных шторок (снизу, диагональ, круг, из центра, раздвижка, сверху) — чтобы карточки не были одинаковыми.
- Шторки и параллакс привязаны к скроллу (scrub), а не проигрываются один раз — выставка «открывается» в темпе посетителя.
- Hero «ФОРМА» не прячется перед анимацией, буквы только приподняты: так LCP не ждёт анимацию.
- Переход в кейс: кросс-документные View Transitions (Chrome 126+, Safari 18.2+), имя `cover` ставится только на нажатую обложку; без поддержки — FLIP-слой через GSAP.
- При возврате на главную обложка «садится» обратно в свою карточку (pagereveal + navigation.activation).
- Табличка с названием на обложке кейса инвертируется для трёх брендов, где обложка того же цвета, что и тема.
- Курсор — белый круг с mix-blend-mode: difference: виден на любом фоне; на сенсорных экранах не включается, над полями ввода прячется.
- Счётчик «Зал 03 / 06» на десктопе — вертикальная этикетка в правом поле, чтобы не перекрывать текст; на мобильном — маленькая плашка в углу.
- На мобильном шапка — сплошная полоса, а не две плашки, сквозь щель между которыми просвечивал текст.
- Без JS: у секций кейсов свой фон через CSS-переменные, все экспонаты видны; через 2,5 с без загрузки скриптов класс js-fail возвращает всё на место.
- «Уменьшить движение»: нет Lenis, шторок, параллакса и View Transitions, всё видно сразу.
- Форма — демо: проверка required браузером, сообщение «Заявка принята (демо)» в aria-live, никаких отправок.
- Контакты — hello@forma.example (зарезервированный домен), телефона нет.
- Адрес для og:image — https://viachkovdesign.github.io/forma/ (константа SITE_URL), потому что имя репозитория «-.» неудобно для адреса.
- OG-картинки сняты Playwright со своих же страниц (1200×630), отдельная для главной и для каждого кейса.
- Скриншоты полных страниц — JPEG, состояния — PNG, чтобы папка не весила десятки мегабайт.
- Lighthouse меряется на локальном сервере с gzip (как GitHub Pages); на python http.server без сжатия цифры ниже — это записано в отчёте.
