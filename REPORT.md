# Отчёт: концепт-сайт «ФОРМА»

## Что сделано

- **Главная** (`index.html`): шапка (знак-арка, меню Работы / Бюро / Процесс / Контакты) → hero с огромным «ФОРМА» и планом экспозиции → лента шести кейсов → «Бюро» (текст + 4 принципа) → «Процесс» (5 этапов, 10–13 недель) → демо-форма → подвал с плашкой «Концепт-проект…».
- **Шесть страниц кейсов** (`cases/*.html`): обложка на весь экран с табличкой-этикеткой, задача, что сделали, данные, «Экспозиция» из пяти экспонатов с музейными этикетками, результаты (помечены «пример»), «Следующий зал» с превью и шторкой.
- **30 SVG-экспонатов + 6 обложек**, все нарисованы кодом в `tools/brands/*.mjs`:

## Как работают шторки

`js/main.js`, блок «Шторки clip-path». У каждого кадра атрибут `data-curtain`, в ленте все шесть разные: `up` (снизу вверх), `diag` (диагональ — растущий треугольник `polygon(0 100%, 0 -100%, 200% 100%)`), `iris` (круг), `center` (прямоугольник из центра), `split` (раздвижка), `down` (сверху). GSAP ScrollTrigger со `scrub: 0.8` ведёт `clip-path` от закрытого к открытому, пока верх кадра идёт от 95% до 35% высоты экрана; одновременно рисунок внутри уменьшается со 1.22 до 1 — эффект «занавес поднимается, экспонат приближается». Экспонаты на страницах кейсов получают шторки по кругу из того же набора.

## Как работает параллакс

- Внутри SVG-обложек группы `<g class="layer" data-depth="…">` двигаются в разные стороны: фон (полосы, сетка, арки) — против скролла, главный предмет — медленно, передний план — быстрее.
- Этикетки и текст кейсов (`data-speed`) идут со своей скоростью относительно рисунков.
- Буквы «ФОРМА» в hero разъезжаются по вертикали с разной скоростью.
- Плавный скролл — Lenis (`lerp: 0.075`), связан с ScrollTrigger через `gsap.ticker`.

## Как работает переход «обложка → кейс»

1. **View Transitions между документами** (Chrome 126+, Safari 18.2+): в CSS `@view-transition { navigation: auto; }`. На странице кейса у обложки постоянное имя `view-transition-name: cover`. На главной имя ставится **только нажатой** обложке в обработчике клика — браузер морфит её прямоугольник в полноэкранную обложку кейса (0,9 с, `cubic-bezier(.76,0,.24,1)`, `object-fit: cover`, чтобы картинка не растягивалась), остальная страница растворяется.
2. **Назад**: событие `pagereveal` + `navigation.activation.from` находят карточку кейса, с которого вернулись, и обложка «садится» обратно в ленту.
3. **«Следующий зал»**: у текущей обложки имя снимается, у превью следующего — ставится, и превью разворачивается в обложку следующего кейса.
4. **Фолбэк FLIP** (браузеры без кросс-документных переходов): копия SVG кладётся в фиксированный слой по координатам карточки, GSAP растягивает его на весь экран, затем переход по ссылке; фон `<html>` страницы кейса заранее окрашен в цвет бренда, поэтому вспышки белого нет. Проверено в Chromium с отключённым `onpageswap` — `screenshots/state-flip-fallback-mid.png`.
5. При «уменьшить движение» переходов нет — обычная навигация.

## Смена шрифтов и цвета

Заголовок каждого кейса и его «Экспозиция» набраны шрифтом бренда; разделы главной тоже меняют шрифт: hero и «Работы» — Unbounded, «Бюро» — Cormorant, «Процесс» — Fira Sans Extra Condensed. У каждой секции есть `data-bg / data-ink / data-muted`; IntersectionObserver по центральной линии экрана переключает CSS-переменные, `body` плавно (0,9 с) перекрашивается вместе с шапкой, счётчиком и курсором. Счётчик «Зал 03 / 06» обновляется так же.

## Что упрощено

- Экспонаты — плоские иллюстрации, без фотореалистичных мокапов (так и задумано — без чужих фото и без 3D).
- Шрифтовые пары брендов собраны из тех же четырёх шрифтов сайта, чтобы не грузить лишнее; разница — в начертаниях и наборе.
- В SVG-обложках параллакс двигает слои только по вертикали.
- Страницы генерирует Node-скрипт: для правки текста нужно пересобрать (`npm run build`), зато шапка и подписи нигде не расходятся.
- Форма никуда не отправляет данные.

## Идеи улучшения

1. Пройтись по экспонатам кейса стрелками клавиатуры: «зал» как слайд-шоу с увеличением экспоната на весь экран.
2. Звуковой слой (шаги, тихий гул зала), включаемый по кнопке.
3. На странице кейса — «до/после»: старая вывеска против новой со шторкой-слайдером.
4. Переключатель «день / вечер» для фасадов: та же иллюстрация с подсветкой вывески.
5. Индивидуальный курсор для каждого зала (кружок оси, отвес, зерно граната).
6. Интерактивная палитра: клик по цвету копирует HEX и показывает, на каких носителях он живёт.
7. Печатная версия кейса (A4 PDF) из того же HTML для отправки клиенту.
8. Английская версия для международного портфолио.
9. Лёгкий конструктор меню на примере «Отвеса»: вписать свои позиции и увидеть табло.
10. Собрать брендовые шрифты в один файл на гарнитуру (кириллица + латиница), чтобы сократить запросы ещё на шесть.

## Как опубликовать
