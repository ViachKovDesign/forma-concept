Зал 05 / 06Винный барСанкт-Петербург2024

Осадок

Бар натурального вина на 28 мест в подвале дома с парадной на Петроградской стороне.

Задача заведения

В баре сорок вин по бокалам, почти все — без фильтрации. Гости пугались мутного вина и спрашивали, не испорчено ли оно, а выбирать из сорока позиций не хотели. Нужно было превратить осадок из страха в повод для разговора и упростить выбор.

Что сделали

  1. 01Логотип с «осадком» в нижней трети букв
  2. 02Винная карта по шкале мутности из пяти уровней
  3. 03Пакет для бутылки, этикетка домашнего вина, подставки
  4. 04Эмалевая табличка у парадной и надписи на подвальных окнах
